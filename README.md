# $4UL$

> Рабочее название. Проект на ранней стадии: идёт этап 1 — минимальное демо.

Образовательная платформа для тех, кто учится и учит с математикой. Конспекты, курсы и задачи живут в одном месте, а тексты с формулами пишутся на LaTeX.

Первый модуль — **«Заметки»**: редактор в духе Obsidian, где вместо Markdown используется упрощённый LaTeX (строгое подмножество, совместимое с обычным TeX), а рядом с исходником показывается живое превью.

## Модули

| Модуль | Что делает | Статус |
| --- | --- | --- |
| Заметки | Дерево папок и заметок, LaTeX-редактор с превью, ссылки между заметками и обратные ссылки, поиск, история версий | В разработке (этап 1) |
| Курсы | Уроки и учебные материалы, в которые встраиваются заметки | Планируется |
| Задачи | Задания с автоматической проверкой ответов (разбор LaTeX + SymPy) | Планируется |
| Аналитика | Прогресс, статистика, рекомендации | Планируется |

## Архитектура

Микросервисы, общающиеся через REST и события в Kafka.

| Компонент | Технологии | Роль |
| --- | --- | --- |
| Frontend | SPA, CodeMirror 6, KaTeX | Редактор, превью, интерфейс платформы |
| Gateway | nginx | Единая точка входа, TLS, сжатие, rate limit |
| Auth | Keycloak | Вход, пользователи, токены (OIDC) |
| Vault service | Java, Spring Boot | Дерево, заметки, версии, права доступа |
| Index service | Node.js, TypeScript | AST заметок, ссылки, полнотекстовый поиск |
| Брокер | Kafka | События об изменениях (transactional outbox) |
| БД | PostgreSQL | Данные сервисов, у каждого своя схема |
| Наблюдаемость | Prometheus, Grafana, Loki, Tempo | Метрики, логи, трейсы |
| CI/CD | Jenkins, Nexus/Harbor | Сборка, тесты, образы |

Ключевые решения:

- **Источник истины — исходный текст заметки.** AST строится из него и всегда может быть перестроен.
- **Один парсер LaTeX** (TS-пакет) для фронтенда и сервера.
- **Сервисы по 12-factor**, чтобы переезд в Kubernetes свёлся к написанию Helm-чартов.

Подробности и обоснования — в [`docs/adr`](docs/adr).

## Структура репозитория

Монорепозиторий:

```
services/        сервисы: vault, index, frontend
packages/        общий код (latex-parser)
contracts/       OpenAPI и схемы событий
infra/           docker compose, конфиги Keycloak, nginx, Jenkins
docs/adr/        архитектурные решения
```
